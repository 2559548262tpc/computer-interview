# 百度 AI 全栈简历模拟面试 Skill

这是一份根据**一面、二面、三面真实逐字面试记录**抽象的 Agent Skill。它侧重面试官的风格、围绕简历的动态追问，以及回答卡住时的渐进式引导，不是固定的百度题库，也不是官方内部面试规范。

## 文件

- `SKILL.md`：主 Skill，含完整执行指令。
- `references/evidence-map.md`：三轮记录的提问风格与证据。
- `references/design-hints-and-evaluation.md`：引导话术、场景树、评价尺度。

## 使用

将整个 `baidu-fullstack-interview-skill` 文件夹放到你所用的 Agent/IDE 支持的 skills 目录，让智能体加载 `SKILL.md`。也可以把 `SKILL.md` 的内容直接提供给支持长提示词的模型。

上传**你自己的简历**之后，发送：

> 请使用 baidu-fullstack-interview Skill，按照我自己的简历模拟百度 AI 全栈**三面**。一次只问一个主问题。回答不完整先追问；卡住时给少量渐进式提示，不要直接告诉我答案。模拟过程中不要评分，结束后再完整复盘。现在开始。

想练一面或二面，只需将“三面”换成“一面”或“二面”。

如希望覆盖全部轮次：

> 使用这个 Skill，依次模拟一面、二面、三面。每一面独立评价，下一面针对上一面暴露的弱点换场景追问；全部结束后给跨轮对比。
