# 轮次差异：一面 / 二面 / 三面各考什么

> 依据多份同公司多轮录音（尤其百度 4 份、字节 2 份、小米 2 份）交叉验证。**难度不是单调递增，而是三种不同性质的难。**

## 一句话总览

| 轮次 | 本质 | 一句话 |
|---|---|---|
| **一面** | 密度与诚实 | 问得多、切得快，看你哪里露底 |
| **二面** | 深度与边界 | 问得少、钻得深，看你会到哪层、边界在哪 |
| **三面/主管** | 判断与可塑性 | 不考知识，考"给你个模糊需求你能推到什么程度"、"能不能带" |

## 一面

- **目标**：筛掉"项目是包装的"和"基础有硬伤"的人。
- **时长占比**：自我介绍 3–5% + 项目深挖 30–45% + 基础广度 8–15% + 算法 25–40% + 反问 5%。
- **特征**：
  - 项目题走"**单点极深**"：百度一面 18 分钟只问一个项目，链路=业务价值→有没有前端→怎么测→部署没→环境→端口→容器→压测→排障→日志→落盘→磁盘满。
  - 基础题走"**广度扫射**"：字节一面 4.8 分钟问 10 个小点（MVCC/幻读/redo/Redis SDS/线程模型）。
  - **算法是硬门槛**：字节一面算法占 42%，且"不给 IO 规范、自己写 case"。
- **给不给提示**：实习一面给台阶多（降标准、半答案）；秋招一面明显减少。
- **面试官角色**：一线工程师/直接用人方，偏"技术尽调"。

## 二面

- **目标**：画"能力雷达图"——你会什么、不会什么、边界在哪。
- **时长占比**：自我介绍 4% + 项目深挖 40–50% + 基础 10–20% + 场景/设计 15–25% + AI 专项 10–50% + 反问 5%。
- **特征**：
  - **知识边界测绘**：连续"这个你做了吗/用到了吗/了解吗"，答不出就记为空白（ES、OAuth2.0、证书、BM25 原理）。
  - **同一问题换 3 种问法**：百度二面"怎么评判 Agent 好坏"问 3 次；蚂蚁二面"为什么这么设计"连问两个 why。
  - **逼量化与归因**：样本多大、优化前后多少、为什么是 0.9、指标掉了怎么排查。
  - **AI 专项占比最高**（大模型应用岗）：RAG、Agent 编排、评估、Harness/SubAgent。
- **给不给提示**：分两极——百度二面给"半答案"，蚂蚁二面"只递刀子"。
- **面试官角色**：后端/资深工程师，结构化、会自答标准、会给"谢谢给你点赞"。

## 三面 / 主管面

- **目标**：判断力、工程品味、可塑性、稳定性。
- **时长占比**：自我介绍 3% + 真实性定性 4% + 反思题 10% + 开放设计题 10–20% + 深度设计/死磕一点 20% + 反问/职业规划 10–15%。
- **特征**：
  - **零八股、零算法**（百度三面、小米二面都是）。
  - **反思题**："如果让你重新做，你会优化什么"（百度三面给了候选人 6 分钟）。
  - **开放设计题**：给一个模糊产品需求（"做个搜索"），考需求澄清→接口设计→被否后迭代。
  - **苏格拉底式**：不给答案，只描述症状（"层级有点深""参数有点多"），让你自己改，改对了给正反馈。
  - **稳定性/匹配**：能实习多久、接不接受城市、职业规划、为什么离开上一段。
- **给不给提示**：**给台阶最多**（"没事儿""没有标准答案""这个后面优化"）。
- **面试官角色**：组长/负责人，自己讲得比候选人多，收尾常是长谈。

|---|---|---|---|---|

## 排结构时的默认模板

**一面（40–50 min）**：开场流程说明(1) → 自我介绍(3) → 项目深挖(18) → 基础广度(5) → 算法(12) → 反问(3)
**二面（45–55 min）**：自我介绍(3) → 项目A(13) → 项目B(12) → 基础/协议(6) → 场景设计(8) → AI专项(6) → 反问(4)
**三面（50–55 min）**：自我介绍(2) → 真实性定性(3) → 反思题(8) → 开放设计(12) → 死磕一个设计点(15) → 反问/职业规划(8)

> 占比可按公司微调：字节一面算法拉到 40%；蚂蚁一面项目/工程题拉到 85%；小米二面软性+匹配拉到 35%。
