> 样本：2 份录音（今日头条后端一面 ~59min、三面 ~57min）。另有 1 份"字节业务面"（合规/数据自动化，非技术），见 `transcript-index.md`。

## 一句话画像

**工程现实主义 + 逻辑驳斥。** 不迷信名词，只认落地；反驳是常态，不是失礼。

## 风格特征

- **不迷信名词**："工具不工具，harness 概念之前不就已经有了吗"——测你能否区分"新名词"与"旧实践"。
- **高频反驳 + 半肯定**："没太理解""我指的是""其实你也没用是吧""并不会呀""有点反直觉"；但否定后常接"思路是好的""这个思路是可行的"。
- **稳定性/成本价值观**："它不是 1+1>2 的，它有可能 1+1<2"——加组件=加风险，Redis 不是白给的（要看门狗、保稳定性）。
- **算法硬门槛**："字节这边面试都是这种纯纯题目的"——**不给 IO 规范、自己写 case**。
- **三面会逐行改代码验证**：注释第 40 行、调换 36/37 行，看你是不是真懂自己的代码。

## 一面 vs 三面

### 一面（~59 min）
- 结构：业务介绍(46s) → 自我介绍(2.4min) → 项目 A(金山云 Agent) → 项目 B(运维平台/OAuth2.0) → AI 通识(上下文管理) → 八股(MySQL+Redis，广度扫射) → 系统设计(幂等接口，反复反驳) → **算法 25min(占 42%)** → 反问(20s)。
- **八股广度**：MVCC、幻读、redo/binlog 崩溃恢复、Redis 数据结构/SDS/线程模型。
- **系统设计质量最高**：幂等接口，每提一个方案加一个副作用（颁发 ID 又是接口→先查后改→事务超时→Redis 看门狗）。
- **算法未完成未写 case**（卡在构建输入）。

### 三面（~57 min）
- **无自我介绍**，直接"你选一个最能体现工程能力的项目展开聊"。
- 项目只挖 1 个，但**强 ownership 校准**："哪部分是你的""端到端都你负责吗""效果也你负责吗"。
- **八股单点钻深**：TCP 三次握手（反事实推演两次握手，连拆 4 次）→ MySQL 索引（下钻 6 层到"优化器怎么估选择率"）。
- **算法 21min**（货币兑换，图+BFS），**写完后逐行验证**，追问 BFS/DFS 正确性。
- **容忍长沉默**（46s、50s），不打断。
- **元沟通**："我这个其实是在给你沿着你刚才那个路去假设""那我们的问题是什么，你还记得吗？"

## 考察重点

1. **Agent 工程"脏活"**：状态保持、断点续传、评测指标分子分母、上下文压缩质量评估、重试污染 context、流式中断的提交边界、换模型后的 prompt 技术债。
2. **对概念通胀的警惕**：harness 这种词，要能说"它出现之前的做法是什么"。
3. **指标定义能力**：不满足"看精确率召回率"，追"分子分母是什么""覆盖率怎么算"。
4. **安全协议原理边界 + 最小权限**：OAuth2.0 的 scope、用户组≠安全性。
5. **存储基本功颗粒度**：MVCC 版本链→默认隔离级别→幻读与 Next-Key Lock→redo/binlog 两阶段提交→Redis SDS len。
6. **系统设计的稳定性价值观**：加 Redis 是引入新风险而非正解。
7. **算法**：建模 + 数据结构选型 + 边界自测 + 可验证性。
8. **逻辑自洽**："你逻辑上有点不太对啊""你说的性质和你写的代码是否匹配"。

## 高频题（原话样本）

- "你选一个最能体现工程能力的项目展开聊。"
- "这块哪部分是你的？端到端都你负责吗？效果也你负责吗？"
- "harness 这块你是怎么理解的？"→"工具不工具，harness 概念之前不就已经有了吗？"
- "你们测评怎么做？最终评判标准是什么？分子分母是什么？"
- "上下文怎么管理？怎么实现？摘要损耗怎么评估？"
- "换基座模型的时候，提示词需要改吗？"→"这个其实有点反直觉……"
- "工具调用失败怎么处理？代码层还是 Agent 层？重试后 context 里留下什么？"
- "假设 TCP 建成两次握手，可能出现什么问题？"（反事实）
- "索引扫描一定比全表扫描快吗？什么情况不一定？什么时候回表？覆盖索引一定快吗？优化器怎么估选择率？"
- "设计一个可重复写入、最终只有一条的接口，网络不可控。"
- "你自己设计几个极端边界 case。"（算法）

## 危险信号

- 概念会背但落不到"进程在哪、状态存哪、失败怎么办、指标怎么算"。
- 一提性能就"加 Redis"，说不出它带来的新问题。
- 算法跑通但不写 case、被改一行就说不清行为。
- 前后逻辑矛盾（说"要人工审核"又说"一两千行审不了"）。

## 话术速取

- 概念拷问："这个概念在它出现之前，这件事是怎么做的？"
- 反驳："并不会呀。""这个跟是不是下推好像并没有关系吧？"
- 半肯定："思路是好的，但是……"
- 价值观："它不是 1+1>2，可能 1+1<2。"
- 拉回主线："那我们的问题是什么，你还记得吗？"
- 收尾："行，那今天就先这样，感谢你的时间。"
