# 小米（小爱同学 / 服务端 + Agent）

> 样本：2 份录音（小米小爱同学服务端实习：一面 ~40min 技术面、二面 ~20min 主管面）。同一位候选人张志瑞。

## 一句话画像

**一面=技术评审（项目选型+指标+AI coding+Java 八股+口述算法）；二面=用人决策（"最核心是什么"+抓矛盾+稳定性）。**

## 一面（技术面 ~40min）

- 结构：寒暄 → **自我介绍给了明确提纲**（"讲做过什么项目、解决什么问题、遇到什么困难"）→ **候选人独白 27%（面试官一句不插）** → 项目深挖两轮 → AI 工程通识 → Agent 评测 → **Java 八股** → **口述算法** → 反问。
- **简历逐条点名核**："你写的 rerank 输入输出是什么""4 个 Agent 失败了谁兜底""配置化的收益是什么"。
- **复合问题多**（一题两点），漏答必重问（MCP 那题原样重问第二问）。
- **低反馈**：大量"嗯/好/嗯？"，不表扬、不复述。
- **八股门槛硬**：HashMap 结构→为什么红黑树→并发问题→ConcurrentHashMap 为什么安全；线程池参数与提交。
- **给提示几乎为零**；唯一"提示"是肯定式复述当钩子（"转成红黑树是吧？"）。
- **收尾干脆**："看时间差不多了""那我们没有就先这样"，不承诺反馈时限。

**考察重点**：RAG 全链路工程判断（多格式解析选型、Excel 双通道、BM25）、检索指标（top1/top5/top10、embedding 横评）、双通道兜底、评测体系（冷启动、ragas、人工终审）、多 Agent 工程化（结构化校验、配置化）、AI coding 真实度（工具有没有 review 工作流）、Java 基础、双指针算法。

## 二面（主管面 ~20min）

- **20 秒就打断自我介绍**："我们现在一个项目一个项目地聊。"
- **只挖 1 个项目，但高密度反驳**：
  - "最核心的是什么？"→ 候选人说"代码生成"→ **"我们说一个最核心的最核心的"** → "代码每个 Agent 不都能生成代码吗？" → "为什么理解成修复能力？生成质量高压根不需要修复啊" → **"站在现在这个视角，你觉得是什么最重要"**。
  - 抓矛盾："你刚才又说一两千行我审核不了。"
  - **元反馈**："你的核心观点是什么？感觉有点漂移了。"
  - 替候选人收口："我总结一下，你觉得就是需求澄清最重要，是吗？"
- **软性三连换壳**：自驱力 → "个人的价值观呢" → "换一个问法，你怎么评价自己？"
- **匹配/稳定性**：为什么离开 TCL、能实习多久、接不接受一线城市、怎么看小米、最快到岗。
- **主动卖点**："我们内部是可以转那个秋招 offer 的。"

## 高频题（原话样本）

- "你先做个自我介绍，重点讲做过什么项目、解决了什么问题、遇到什么困难？"
- "PDF/PPT/Excel/Word 各种格式，你是怎么选的？双重校验解决什么问题？"
- "Excel 双通道，什么时候走 HTML 转 markdown 进 rank，什么时候建表查搜？"
- "千问 3 rerank 的输入输出是什么？对哪个指标提升最明显，为什么？"
- "4 个 Agent，失败了谁兜底？判错了怎么处理？"
- "配置化的收益是什么？新增一个 Agent 要做什么？"
- "日常开发用哪些 AI 工具？生成的结果怎么 review？有没有代码审查工作流？"
- "MCP 解决了什么问题？和自建 HTTP 工具调用比优势在哪？"
- "HashMap 底层结构？为什么转红黑树？并发有什么问题？ConcurrentHashMap 为什么安全？"
- "线程池核心参数？任务提交流程？"
- "（二面）你觉得这个项目最核心的是什么？"
- "（二面）从开始到最后生成，中间有几次人工审核？"
- "（二面）为什么离开上一段实习？能实习多久？怎么看小米？"

## 危险信号

- 一面：只会说"用了 RAG/rerank"，说不出选型理由与指标；AI coding 只会"看效果"没有 review 工作流。
- 二面：答不出"最核心的那一个"（只会罗列模块）；前后矛盾；漂移跑题；稳定性答不上（时长/城市）。

## 话术速取

- 结构化指令："重点讲做过什么项目、解决了什么问题、遇到什么困难。"
- 漏答重问："呃，就是它和自建 HTTP 工具调用相比，优势在什么地方？"
- 逼收敛："我们说一个最核心的最核心的。"
- 抓矛盾："那你刚才又说一两千行我审核不了。"
- 元反馈："你的核心观点是什么？感觉有点漂移了。"
- 换壳："换一个问法，你是怎么评价自己的？"
