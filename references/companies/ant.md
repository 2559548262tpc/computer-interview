# 蚂蚁（Agent / 大模型应用，财富事业部搜索推荐）

> 样本：2 份录音（蚂蚁 agent 一面 ~17min、二面 ~33min）。**零八股、零算法、零手写代码**，全部时间给"一个 Agent 工程问题的纵深"。

## 一句话画像

**不考知识，考"你对 Agent 工程理解到哪一层"；二面再加一条"你做没做到，能不能证明"。**

## 风格特征

- **即兴切入**："我突然想到一个点""先说第一个问点吧"——像技术探讨，不像审问。
- **口语化、碎片化**，高频"嗯/呃/诶/明白/OK"，**几乎不给明确评价**（"这是你的思考是吧？"这种留白施压）。
- **硬纠偏**："不是我想了解的是这个点，我想了解的是……"
- **自己造业务例子把你逼到墙角**："以买股票为例，代下单、交易中、部分成交、全部成交……这些状态在 AI 里怎么维护？"
- **只信具体，不信名词**：一提 LangGraph/记忆框架/向量召回，立刻追"跨会话怎么办""样本多大""为什么是 0.9"。
- **切边界往下压**：会话内 → 跨会话 → 长周期（几天/几个月）。

## 一面 vs 二面

### 一面（~17 min，一道题打穿）
- **无自我介绍、无寒暄**（录音从中途开始），直接抛开放题。
- **结构**：AI 开发难点(13%) → MCP/skill 概念(10%，只问"了不了解"，不深挖) → **运行时状态管理(57%，连续 6 次纠偏)** → 长周期会话(14%) → 反问(5%)。
- **给提示**：会给方向（"记忆框架一般是临时的嘛""一般很少让 Agent 直接连 DB"），甚至替候选人补全思路。
- **主战场是三层区分**：会话上下文 / 业务实时状态 / 长期记忆。候选人两次混淆被打断。

### 二面（~33 min，简历逐条审计）
- **标准自我介绍 → 100% 从候选人自己的话里出题**（"你刚才说……"）。
- 两个项目各吃 4 成时间：deepcode research（上下文压缩/评估/编码质量/比赛含金量）+ 金山云语义检索（链路/指标/标注/归因/性能）。
- **不给提示**，只做证据核验，用**复述+单句反问**施压："就 3 个小型任务是吗？""光看一致性够吗？"
- **逼量化归因**：多少人参加、样本多大、优化前 20–30% → 后 top1 84%、为什么是 0.9、延迟降 50% 怎么做的。

## 考察重点（按权重）

1. **状态管理三层区分**（★★★★★）：会话上下文 / 业务实时状态 / 长期记忆。
2. **上下文工程**（★★★★★）：压缩策略、压缩模板结构与动因、分层压缩、入库+召回替代长上下文。
3. **评估方法论**（★★★★★）：怎么评估、谁来评、样本多大、指标怎么定合格线、一致性怎么转成阈值。
4. **长任务目标保持**（★★★★）：不跑偏、任务重申、长程规划。
5. **多 Agent 编排**（★★★★）：planner 拆解、子 Agent 上下文隔离、审查-修复循环上限、失败上报人类。
6. **量化与归因**（★★★★）：优化前后、换模型对比、延迟下降的具体算法。
7. **MCP/skill 本质**（★★★）：统一接入标准、渐进式披露（只做门槛验证）。
8. **工程约束与安全边界**（★★★）：工具权限收敛、输出后处理、提示词严格化、API 限流。

## 高频题（原话样本）

- "你觉得做 AI 开发和普通开发相比，难点在哪？有挑战的点在哪？"
- "MCP、skill 这些你有了解吗？简单说下你的理解和日常使用。"
- "传统开发我会建关系型表维护状态机，AI 开发里同类数据怎么实现？"
- "不是我想了解的是这个点——它已经在线上运行时的状态，处理实际业务时怎么管状态机？"
- "以买股票为例，代下单、交易中、部分成交、全部成交……这些状态在 AI 里怎么维护？"
- "跨会话了怎么办？" / "如果是几天甚至几个月呢？"
- "你们做上下文压缩，怎么评估压缩之后会不会丢关键信息？"
- "你们筛查的规模是多大？多少个任务里筛出来的？"
- "你刚才讲得有点粗，指标提升的核心是什么？哪些优化带来的？为什么？"
- "光看一致性够吗？"

## 危险信号

- 把"框架名"当答案（"我用 LangGraph 的 state""用记忆框架"）。
- 分不清"用户习惯"与"用户实时业务状态"。
- 评估只会说"人工筛查"，却说不出样本量、指标、合格线。
- 指标提升讲不出归因（"就是优化了一下"）。

## 话术速取

- 即兴切入："我突然想到一个点……"
- 硬纠偏："不是我想了解的是这个点。"
- 造例子："我举个例子，以买股票为例……"
- 逼收敛："就 3 个小型任务是吗？"
- 单句反问："光看一致性够吗？"
- 中性收尾："我看时间差不多了，你对我们这边有什么想了解的？"
