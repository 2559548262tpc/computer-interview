## 三、样本标签体系（用于检索与生成）

每份录音可打以下标签，生成时按需筛：
- `公司`：百度/字节/蚂蚁/高德/小米/其他
- `岗位硬度`：核心研发 / 支撑类（如合规数据自动化）
- `轮次`：业务一面 / 技术一面 / 二面 / 主管三面
- `施压方式`：无压力 / 连续性（答不上就换）/ 逻辑闭环（抓矛盾）/ 证据链（逼量化）
- `是否给提示`：代答型 / 钩子型 / 换壳型 / 不给
- `收口话术`："我总结一下…是吗" / "你的核心观点是什么" / "我们说一个最核心的"
- `批次`：实习 / 校招 / 日常实习（当前全为实习系）

## 四、新增录音的迭代流程

1. **转写**：录音 → `transcripts/<名称>.md`（用项目里的 `_convert.py` 统一格式）。
2. **识别**：先读开头 30 行，判断公司/岗位/轮次/是否为闲聊或设备调试；不确定就标"不确定"并写依据。
3. **结构拆解**：按 `rounds.md` 的维度提取——基本信息、面试结构（阶段+占比）、问题清单（带原话）、追问链、风格画像、考察重点、引导话术。
4. **归并与校验**：
   - 与同公司已有样本对照，**冲突时标注"样本间不一致"**，不强行统一。
   - 更新对应 `companies/<公司>.md`；新公司则新建文件 + 本表登记。
5. **更新批次文件**：若是秋招样本，回填 `internship-vs-autumn.md` 的"待补充"清单，并把推演结论改为实证。
6. **更新本表**：补一行，标证据强度。
